# Mi proceso para hacer una página web

El proceso de comenzar a programar me pareció fascinante. Me encantó empezar con acción desde la primera clase! A continuación, los pasos para hacer una página web:


1. **Descargar la plantilla del profesor**

Como estamos apenas aprendiendo a programar, el profesor nos proporcionó la plantilla general para que la descarguemos.


2. ** Cambiar datos** 

Despues de descargar la plantilla, cambiamos el nombre y reemplazamos con nuestra cuenta de Github

3. Dominar **Markdown** (texto, listas, tablas, código).
4. Configurar la **navegación** (sidebar, secciones, orden).
5. Agregar **imágenes, videos** y otros recursos.
6. Ajustar **estilos** (logo, colores, footer).
